# Script para calcular factorial de números muy grandes

Para compilar: 

```
g++ -std=c++17 -O3 FactorialGrande.cpp -o factorial_grande 
```

```
g++ -std=c++17 -O3 factorial_binsplit.cpp -o factorial_binsplit
```

Para ejecutar (ejemplo)

```
./factorial_grande 1000
```

```
./factorial_binsplit 1000
```
